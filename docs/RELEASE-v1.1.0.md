# Codex Balance Widget v1.1.0

## 更新

- 展开窗口右上角新增横杠最小化按钮：点击立即收回为头像气泡，无需等待倒计时，重新展开保留原尺寸。
- 修复 Codex 保持运行时切换账号后额度不同步：每秒检查登录状态文件元数据，变更时清空旧额度及重置卡、终止旧请求并重建数据连接。
- 通过官方账号接口检查登录状态；退出登录时显示提示，重新登录后自动同步。
- 数据读取失败后重新连接，避免长期卡在异常的数据进程上。
- 中等高度提前使用横向布局，修复额度标签与重置卡标题重叠。
- 纳入窗口层级优化：点击后不抢焦点地置顶，收回或隐藏时解除置顶。

## 下载与升级

下载本页的 `CodexBalanceWidget-v1.1.0.zip` 和 `.zip.sha256`，验证哈希后解压，运行 `installer/Install.ps1` 更新。
系统要求：Windows 11 x64、Microsoft Store/MSIX 版 Codex、系统自带 .NET Framework 4.8 和 Windows PowerShell 5.1。
安装包不包含 Codex 官方运行时、用户账号、设置、头像或日志。

- 11 项核心测试、12 项基础设施测试通过；包括持续运行时账号切换、退出/重新登录、未完成旧请求隔离，以及最小化与尺寸恢复。
- 11 项状态服务测试、源码安全检查、构建产物检查、冒烟检查通过。
- 本机可信官方运行时的真实账号/额度只读连接检查通过；重复的未变化账号通知不会触发重连。
- 已检查浅色/深色的 300×320、300×220、240×148 六张渲染图。
- 账号切换使用模拟 app-server 回归；尚未完成真人双账号切换和干净 Windows 11 设备安装/卸载验收，因此本次保持预发布状态。
- 文件元数据检测适用于 Codex 使用 `CODEX_HOME/auth.json` 保存登录状态的场景；仅系统凭据库或外部注入登录方式的跨进程账号切换尚未验证，必要时需重启小窗。
- 额度和重置卡的可用性取决于官方接口，未返回的内容显示为不可用。

接口依据：[Codex App Server](https://learn.chatgpt.com/docs/app-server)。组件只查询登录类型和额度，不读取凭据文件内容、不调用额度重置操作。
